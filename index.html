Map can't load from a local file

This map uses external libraries (Leaflet, map tiles) that Chrome blocks when opened directly as a file:// path. To view it:

Option 1: Host it on any web server — including GitHub Pages (free, 2 min setup).
Option 2: In Chrome, go to chrome://flags/#unsafely-treat-insecure-origin-as-secure — but hosting is much easier.
Option 3: Use the VS Code Live Server extension to serve it locally.
